## 보고서가 갖출 것

`docs/TASKS.md` 는 "구현했다"가 아니라 **"돌려서 이 결과가 나온다"**가 완료라고 못박습니다.
보고서도 같은 기준을 따릅니다.

1. **완료 기준 대조** — 기준마다 통과 여부와 그 근거가 되는 실제 출력
2. **감리자가 직접 확인하는 법** — 그대로 실행하면 같은 결과가 나오는 명령
3. **문서와 다르게 한 것** — 무엇을, 왜, 승인을 받았는지
4. **미완** — 기준을 낮추지 않고 사실대로. 못 한 것은 못 했다고 적습니다
5. **다음 단계 인수인계**

숫자를 적을 때는 어디서 나온 값인지 함께 적습니다. 근거 없는 수치는 넣지 않습니다.
