# ADR-004. 재생을 클라이언트에서 한다

- **상태**: 결정
- **결정일**: 2026-08-08

## 배경

파트별 연주를 서버에서 오디오로 만들어 내려줄 수도, 브라우저에서 음표 데이터로 직접 소리를 낼 수도 있다.

## 결정

**1차는 클라이언트에서 재생한다.** Tone.js Sampler + 압축 피아노 사운드폰트(2MB 이하).

## 근거

| 항목 | 클라이언트 | 서버 렌더링 |
|---|---|---|
| 빠르기·음량 변경 | 즉시 | 다시 렌더링 |
| 오디오 저장 | 없음 | 파트당 파일 |
| 작업 큐 | 재생에 불필요 | 필요 |
| 첫 응답 | 사운드폰트 2MB | 오디오 수 MB |

**서버 렌더링은 가창 합성이 들어가는 1.5차에 처음 필요해진다.** 1차에서 미리 만들 이유가 없다.

## 음색

**피아노 단일 악기.** 음정을 익히는 데는 명료한 어택이 낫다. 악기 선택은 2차.

악기가 하나뿐이라 음량만으로는 파트가 섞인다. **좌우 정위를 함께 쓴다.** 합창단 배치대로 소프라노 -0.5, 알토 -0.2, 테너 +0.2, 베이스 +0.5.

## 확장 대비

재생기를 `PartPlayer` 인터페이스로 추상화한다. 1차는 `MidiPartPlayer`, 1.5차에 `AudioPartPlayer`를 더한다. 상세는 `docs/ARCHITECTURE.md` 6장.
