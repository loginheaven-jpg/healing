# ADR-002. 기존 저장소 개선이 아니라 신규 구축

- **상태**: 결정
- **결정일**: 2026-08-08

## 배경

이전 버전(`loginheaven-jpg/chorus`)이 존재하며 실제로 동작한다. 벡터 PDF 파싱이 완성도 높고 테스트 57건을 통과한다.

## 결정

**신규 저장소를 만들고 선별 이식한다.**

| 대상 | 처리 |
|---|---|
| `server/omr/*.ts` (3,065줄) | **통째로 이식** |
| `tests/fixtures/*` | **통째로 이식** |
| `docs/decisions/*` | 참고 후 재작성 |
| `_core/*` (Manus 스캐폴드 12파일) | 버림 |
| `client/src/*` | 버림 (UI 전면 교체) |
| `drizzle/*` (MySQL) | 버림 (Postgres로 재작성) |
| `AIChatBox.tsx`, `Map.tsx` 등 | 버림 (템플릿 잔재) |

## 근거

**첫째, 플랫폼 결합.** `_core/`가 Manus 스캐폴드이며 OAuth가 Manus에 묶여 있다. 12개 파일이 이를 참조한다. Railway·Cloudflare로 옮기면 어차피 걷어내야 한다.

**둘째, 바뀌는 것이 너무 많다.** 인증 모델(Manus OAuth → 통행 암호), DB(MySQL → Postgres), UI(전면 교체), 스키마(쉼표·마디 좌표 추가). 남는 것이 `server/omr`뿐이다.

**셋째, 이것이 결정적이다.** 클로드 코드는 깨끗한 트리에서 훨씬 잘 작동한다. 지도 컴포넌트와 AI 채팅 상자가 굴러다니면 그것이 프로젝트의 일부인 줄 알고 참조하거나 보존하려 든다. 지시서로 일일이 막는 것보다 처음부터 없는 편이 낫다.

## 기각한 대안

**기존 저장소 가지치기** — git 이력과 배포 URL(chorus.manus.space)이 보존된다. 그러나 Railway로 옮기므로 배포 URL 명분이 사라진다. 이력은 기존 저장소를 남겨 두면 언제든 참조할 수 있다.

## 결과

- 기존 저장소는 **삭제하지 않고 참조용으로 남긴다.**
- 이식한 코드에 출처 주석을 남긴다.
