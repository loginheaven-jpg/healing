# UI 시안

구현의 기준입니다. **빌드 대상이 아닙니다.**

| 파일 | 화면 | 기준 폭 |
|---|---|---|
| `mobile.html` | 서재, 연습 | 375~430px (휴대폰) |
| `desktop.html` | 악보 올리기, 인식 확인 | 1920×1080 (PC) |

## 쓰는 법

1. 브라우저로 열어 배치와 동작을 확인합니다.
2. **CSS 변수(`:root`)를 그대로 디자인 토큰으로 옮깁니다.** 색을 임의로 바꾸지 마십시오.
3. 문구를 그대로 씁니다. `docs/SPEC.md` 4장에 정본이 있습니다.

## 디자인 토큰

```
--ink:#14161A   본문 · 잉크
--paper:#FBFAF7 배경
--panel:#FFFFFF 카드
--rule:#CFD1CB  선 · 오선
--wine:#7A2E3F  강조 · 소프라노
--amber:#9A6516 주의 · 알토
--sage:#3F6353  정상 · 테너
--blue:#2C4A6E  베이스
```

글꼴 셋을 역할별로 나눕니다.

| 역할 | 글꼴 |
|---|---|
| 제목 · 가사 | Gowun Batang |
| 본문 | IBM Plex Sans KR |
| 수치 · 마디 번호 · 코드 | IBM Plex Mono |

수치를 고정폭으로 두면 숫자가 흔들리지 않아 진단 화면이 안정됩니다.

## 서명 요소

**오선 5줄을 구조 장치로 씁니다.** 장식이 아닙니다.

- 파트 믹서: 파트마다 오선 한 줄. 고른 파트는 진하고 굵게, 나머지는 흐리게, 끈 파트는 점선
- 신뢰도 게이지: 오선 5줄이 점수만큼 채워짐
- 업로드 표시: 오선 위의 음표 하나

## 데스크톱 화면의 두 가지 장치

**겹쳐보기** — 원본 위에 인식 결과를 파트색 동그라미로 얹습니다. 어긋난 곳이 한눈에 보입니다.

**파트별 음역 띠** — 옅은 띠가 통상 음역, 진한 띠가 실제 분포입니다. 옥타브 오류가 나면 띠가 통째로 벗어나 보입니다. 시안에서 [한 옥타브 내리기]를 눌러 보십시오. 테너 띠가 제자리로 돌아옵니다.

## 시안에 없는 것

시안은 상태 몇 가지만 보여줍니다. 아래는 구현하면서 채워야 합니다.

- 빈 서재
- 인식 실패
- 업로드 중 오류
- 통행 암호 화면
- 휴대폰에서 데스크톱 화면 접근 시 안내

**새 화면이 필요하면 먼저 제안하십시오.** 임의로 만들지 마십시오.
